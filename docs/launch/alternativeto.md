Short description:

Automatically save accepted coding solutions to GitHub, organized by LeetCode topic, Codeforces and CodeChef rating, GeeksforGeeks difficulty, and CSES section.

Detailed description:

SolveBase is a free browser extension that saves newly accepted solutions to a public GitHub repository and updates a managed README summary. It supports LeetCode standard problem pages, Codeforces, CodeChef, GeeksforGeeks practice, and CSES problem set tasks.

LeetCode solutions use one primary topic folder. Codeforces and CodeChef use the problem rating; GeeksforGeeks uses difficulty; CSES uses section. On Codeforces, provisional pretest results stay pending until the final accepted verdict.

GitHub connection uses OAuth with `public_repo`, without manual PAT setup. Source code and repository writes travel directly from the extension to GitHub. Existing personal README content outside the managed block is preserved.

Private repositories, historical bulk import, and LeetCode contest or Explore editors are not supported. Pending verdicts and GitHub retries use bounded local recovery windows.

Alternative relationship: LeetHub — both archive accepted coding solutions on GitHub; SolveBase adds Codeforces, CodeChef, and CSES and uses topic/rating folders. Compare the specific LeetHub project or fork before choosing.
